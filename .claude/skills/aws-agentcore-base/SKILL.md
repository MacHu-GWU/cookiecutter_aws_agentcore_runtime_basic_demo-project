The best practices this repo has settled on for AgentCore projects: a multi-environment scaffold centered on AgentCore Runtime, which can host an agent or an MCP server, deployed by the AgentCore CLI. This skill holds the decisions; the official docs are looked up live (see `01`).

For the project's general AWS and CDK conventions (config, environments, boto session, the `one` singleton, stacks, mise tasks), use the `pywf-aws-cdk-base` skill. This skill covers only what is specific to AgentCore.
