How an AgentCore project made from this template is built: AgentCore Runtime hosting MCP servers and agents, deployed by the AgentCore CLI, in several environments. This skill holds the decisions; the official docs are looked up live (`00`).

For the project's general AWS and CDK conventions (config model, environments, boto session, the `one` singleton, stacks, their tasks), use the `pywf-aws-cdk-base` skill. This skill covers only what is specific to AgentCore.

## The design

`references/99-ood.md` is the operation-oriented design: every OP and sub-OP with its entry point (EP), footprint (FP), and command (CMD), and the refactor checklist. Read it before refactoring an AgentCore module or deciding which OP new work belongs to.

## References

One reference per OP, numbered `<OP><part>`: `10` is OP-1, `30` and `31` would be two parts of OP-3. Lower numbers are lower in the stack and come first in the work; a reference cites only lower numbers. For a question, read only the file that covers it.
